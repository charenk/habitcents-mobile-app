# EmptyState (components/ui/EmptyState.tsx)

## Direction (current)
The one empty-state primitive: an optional mark, optional title, optional body, and one optional text action, either a sage CTA (`tertiaryBrand`, ADR 0038) or a quiet underlined `link` (Button's `link` variant, Charen 2026-09-07), in a 12pt centered stack. Every pane-level zero state is exactly three things: art, one hook line, one text line. The mark is either a 96pt illustration (`illustration`, named from `constants/emptyArt.ts`) or a 28pt slate icon (`icon`); a state names one, never both. `inline` leaves the container to the caller; `fill` adds the default icon and pane padding. Explanatory prose never renders here: the ordered steps list ADR 0039 added is gone.

## States
With or without each part; inline / fill; art or glyph.

## Decisions
- 2026-09-07 (Charen): `fill` centres, and any block holding art is floored to the standard block height. Why: `fill` used to be a 40pt top pad and nothing else, so every fill pane was top-anchored and only Today (with its own wrapper) centred; and centring a stack centres the whole stack, so a one-line and a two-line title put the 96pt art at different heights and a swipe between sibling panes showed it jump. The wrapper lives in the primitive rather than in each caller so N panes cannot drift apart the way their top paddings did (Money's Spent sat 2pt above its siblings for a week). The floor is a minimum, never a clip: content exceeds it under Dynamic Type. Callers give the wrapper a height by growing their scroll content to the pane in the empty case only, and trade the 100pt end clearance for 24 there so the centre is not pulled 50pt high. Rejected: a fixed top offset (does not centre on a tall device), and anchoring the art alone (a second layout mode). Pinned by `__tests__/emptyStateGeometry.test.tsx`.
- 2026-09-07 (Charen): the `steps` and `stepsTitle` props are removed, and a `link` slot is added. Why: "let's not add explainer text in the empty state pattern". True zero on Kept still has to tell the mechanic somewhere, so it now offers one underlined link ("Learn how skips and habits work") that opens `components/today/HowItWorksSheet.tsx`, and the pane goes back to mark, hook, one text line, the same silhouette as Spent Zero. The props went rather than staying idle because this file's own Open note said the slot was an exception, not an opening; removing the only caller removes the exception. Rejected: a link beside the steps (six elements on a three-element pattern), and keeping the props for a future caller (that future caller is exactly what the rule guards against). Reverses ADR 0039's inline explainer; a superseding ADR belongs in the ops repo.
- 2026-09-07: the link is Button's `link` variant, slate, regular, 13pt, underlined, the first underlined text in the app. Why: it has to read as a different kind of thing from the sage CTA that can sit above it, and sage says "do the thing" while an underline says "read about the thing". Renders under the CTA when both exist. Pinned by `__tests__/emptyStateSurfaces.test.tsx` and `__tests__/actionDock.test.tsx`.
- 2026-09-05: Insights' Leak finder Zero state left this primitive rather than being bolted onto it (`components/insights/LeakFinderTeaser.tsx`). Why: it needs an explanation, a research invitation, a reward line and a remembered confirmation, which is four more parts than art, hook, link. Widening EmptyState to fit would have made the one-hook rule negotiable for every other pane; a separate component keeps the exception visible and local. It borrows this primitive's proportions (96pt art, 12pt centered stack, fill padding) so the panes still feel like one family. Decision 0009. See the `steps` note under Open: this is the second time that pressure has come, and both times the answer was to keep the rule.
- 2026-09-05 (review): each step row is ONE accessible element, numeral composed into its label ("1. Log what...") and keyed by index. Why: two bare Texts read as two VoiceOver stops per step, six for three lines, and a text key would collide if a locale ever repeats a line. Matches ExpenseRow's row idiom. ADR 0039 review.
- 2026-09-05: `steps` and `stepsTitle` add an ordered explainer between the hook and the CTA, with exactly one caller. Why: Today's Kept true-zero is the only state in the app where the user has no evidence of their own to read, so the mechanic has to be told rather than shown. The list is left-aligned against the rest of the centered stack, because centred numerals stop reading as a list. Numerals come from the index, so copy never carries "1." and a translation cannot renumber. ADR 0039. **REVERSED 2026-09-07:** the props are gone; the telling moved behind a link into HowItWorksSheet (which keeps the one-stop-per-row idiom).
- 2026-09-05: every empty state is one line, not two. The six pane-level bodies are gone; the app standard is a single hook. Why: the body either restated the title or explained a control the CTA already offers. Closes the open question this file has carried since 2026-09-04. ADR 0037.
- 2026-09-05: the CTA is text only. Why: beside 96pt art and one hook, a bordered pill was the heaviest thing in a pane meant to read quiet; the 44pt target and the PRD's concrete-first-action rule both hold. ADR 0037. **Superseded same day on colour by ADR 0038:** the variant is `tertiaryBrand` (sage), because slate made the pane's only action its quietest element.
- 2026-09-05: pane-level zero states carry a 96pt 3D illustration instead of a shared 28pt glyph. Why: seven surfaces rendered the identical `ChartLine` mark, so the states read as interchangeable and none felt like the place it was. Rejected: distinct lucide glyphs per surface, which fixes sameness but not flatness. ADR 0036.
- 2026-09-05: `illustration` is layout-independent, not gated on `fill`. Why: Today's two zero states are deliberately `inline` (their own wrapper centres the hook between the chips and the dock), so a layout gate would have left Today on 28pt beside 96pt siblings, reviving the two-scale drift this primitive exists to end.
- 2026-09-05: art and glyph share `testID="empty-state-icon"`; the art adds `empty-state-art`. Why: the pinned contract is "a zero state carries a visual mark", which both branches satisfy, so swapping one for the other cannot silently drop the mark.
- 2026-09-05: the art is decorative and hidden from assistive tech. Why: the title and CTA already carry every word a screen reader needs, matching EmojiTile's decorative mode and the glyph it replaced.
- 2026-09-05: `fill`'s `ChartLine` default is kept though every fill caller now names its own mark. Why: same reasoning as `Icon.tsx`'s FALLBACK_GLYPH, a missing mark must degrade to something rather than to a hole.
- 2026-09-04: `body` is optional; Today's two zero states pass none. Why: the body repeated the title; Money, Insights and Categories keep theirs for now. ADR 0033.
- Empty-state unification pass: one primitive replaces four treatments.

## Open
- Closed 2026-09-07: the `steps` slot. It was a deliberate exception and it is gone; the pressure it recorded was answered by moving the explanation off the pane.
- `today-kept` is the last placeholder. It is blue and gold while kept is sage everywhere else, including the chip label directly above it, and at 96pt it reads as a blue ball with an orange ribbon because the gold speckle becomes noise. Seen 2026-09-05 on Today, Kept Zero. A stack of coins (which depicts accumulation, as the kept counter does) or a piggy bank would fix both problems; a green variant would be better still, since kept is the one concept in this app that owns a colour and no illustration currently honours it.
- Rejected for this slot, 2026-09-05: a leather wallet with cards. The Money tab's own icon is a wallet (`app/(tabs)/_layout.tsx`), so it would point at another tab from directly above that tab's icon; cards fanned out is the gesture of paying, not of keeping; and a wallet cannot show accumulation.
- Dynamic Type: verified 2026-09-05 at accessibility-extra-extra-extra-large on the iPhone 16 simulator. The art holds 96pt while the body grows uncapped; Today's Spent Zero and Money's Spent Zero both keep art, title, body and CTA on screen with room to spare. Fixing the art's size is what makes that work, since art that grew with the text would push the CTA off. Still owed a real device pass with VoiceOver.
